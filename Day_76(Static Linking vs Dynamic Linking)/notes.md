# Day 76 — Static Linking vs Dynamic Linking (C++ vs Python)

Today I learned how programs connect with libraries and how this differs between C++ and Python.

---

## 🔗 What is Linking?

Linking is the process of connecting program code with external libraries required for execution.

---

## 🧠 Static Linking

- Libraries included inside executable  
- Faster execution  
- Larger file size  
- No runtime dependencies  

Mostly used in C++.

---

## 🧠 Dynamic Linking

- Libraries loaded at runtime  
- Smaller executable  
- Easier updates  
- Requires external dependencies  

Used heavily in Python.

---

## 🎯 Why This Matters

- Explains performance differences  
- Helps understand deployment issues  
- Improves system-level knowledge  

---

## 🏁 Summary

Static linking = speed & independence  
Dynamic linking = flexibility & modularity
