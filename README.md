## ⭐ About This Repository

This repository documents a **complete 100-day challenge** focused on building strong fundamentals in:

| Area | Topics Covered |
|------|----------------|
| 🧠 **Logic Building** | Problem-solving, recursion, closures, decorators |
| 📚 **DSA** | LL, DLL, Stack, Queue, Deque, Heap, Sorting, Searching |
| 🐍 **Python Internals** | Memory, GC, del keyword, iterators, generators |
| 📊 **Statistics & Math** | Mean, median, mode, SD, variance, IQR, correlation |
