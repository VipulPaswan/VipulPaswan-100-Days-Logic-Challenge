# Day 93 — Relation vs Function (Math for AI & Data Science)

Today I studied the difference between Relation and Function, a key mathematical concept behind ML models.

---

## 📐 What is a Relation?

A relation is a set of ordered pairs showing a relationship between inputs and outputs.

- One input can have multiple outputs
- No restriction on mapping

---

## 📐 What is a Function?

A function is a special type of relation where:

- Each input has exactly one output
- Output is uniquely defined

---

## 🎯 Key Difference

Relation → One input may map to many outputs  
Function → One input maps to only one output  

---

## 🤖 Why This Matters in ML

- ML models are functions  
- Predictions must be unique  
- Training = finding best function  

---

## 🏁 Summary

Functions bring consistency and predictability, which is essential for AI models.
