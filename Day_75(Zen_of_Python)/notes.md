# Day 75 — Zen of Python

Today I studied the philosophy that defines how Python code should be written.

---

## 🧘‍♂️ What is the Zen of Python?

A set of 19 guiding principles that encourage clean, readable, and maintainable code.

View it using:
import this

---

## ✨ Core Principles

- Simple is better than complex  
- Readability counts  
- Explicit is better than implicit  
- There should be one obvious way to do it  
- Errors should never pass silently  

---

## 🎯 Why This Matters

- Produces maintainable code  
- Encourages clean architecture  
- Makes Python human-friendly  

---

## 🏁 Summary

Python is a philosophy, not just syntax.
