# Day 83 — Mode Explained (Frequency-Based Measure)

Today I studied Mode, a measure of central tendency based on frequency.

---

## 📊 What is Mode?

Mode is the value that appears most frequently in a dataset.

---

## 🧠 Types of Mode

- Unimodal → One most frequent value  
- Bimodal → Two most frequent values  
- Multimodal → More than two frequent values  
- No mode → All values occur equally  

---

## 🎯 When to Use Mode

- Categorical data  
- Discrete values  
- Identifying common patterns  

---

## 🏁 Summary

Mode highlights the most common value and is especially useful when averages are not meaningful.
