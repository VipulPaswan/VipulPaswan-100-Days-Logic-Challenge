# Day 99 — ReLU Activation Function Explained

Today I studied the ReLU (Rectified Linear Unit) activation function, which is widely used in deep learning.

---

## ⚡ What is ReLU?

ReLU(x) = max(0, x)

- Outputs input if positive
- Outputs 0 if input is negative

---

## 🧠 Why ReLU is Important

- Faster computation
- Reduces vanishing gradient problem
- Enables deep neural networks

---

## 🤖 Where ReLU is Used

- Hidden layers of neural networks
- Convolutional Neural Networks (CNNs)
- Deep learning models

---

## ⚠️ Limitation

- Dying ReLU problem
- Neurons may stop learning

---

## 🏁 Summary

ReLU is simple, fast, and powerful — the backbone of modern deep learning.
