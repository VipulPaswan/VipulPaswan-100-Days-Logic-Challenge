# Day 98 — Sigmoid Function

Today I studied the Sigmoid Function, a widely used activation function in machine learning.

---

## 📈 What is the Sigmoid Function?

The sigmoid function maps any real-valued input into a value between 0 and 1.

This makes it suitable for probability-based predictions.

---

## 🧠 Key Properties

- Output range: (0, 1)
- Smooth and continuous
- S-shaped curve

---

## 🤖 Usage in Machine Learning

- Logistic Regression
- Binary classification
- Output layer of neural networks

---

## ⚠️ Limitations

- Vanishing gradient problem
- Not ideal for deep networks

---

## 🏁 Summary

Sigmoid is essential for binary decisions and probability modeling in AI.
