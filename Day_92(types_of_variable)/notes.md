# Day 92 — Types of Variables (Categorical vs Numerical)

Today I studied different types of variables used in statistics and data science.

---

## 📊 What is a Variable?

A variable is a characteristic or attribute that can take different values.

---

## 🧠 Categorical Variables

Used to represent categories or labels.

### Types:
- Nominal → No order (Gender, City)
- Ordinal → Ordered (Small, Medium, Large)

---

## 🧠 Numerical Variables

Used to represent measurable quantities.

### Types:
- Discrete → Countable (Number of items)
- Continuous → Measurable (Height, Weight)

---

## 🎯 Why Variable Type Matters

- Determines preprocessing steps  
- Affects algorithm choice  
- Impacts model performance  

---

## 🏁 Summary

Understanding variable types is essential before data modeling.
