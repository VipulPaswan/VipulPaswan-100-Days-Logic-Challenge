# Day 87 — Percentiles Explained

Today I studied Percentiles, which describe the relative position of a value within a dataset.

---

## 📊 What are Percentiles?

Percentiles indicate the value below which a given percentage of observations fall.

---

## 🔢 Example

80th percentile means 80% of the data values are below that point.

---

## 🎯 Why Percentiles are Important

- Compare individual performance  
- Understand relative ranking  
- Handle skewed data better than averages  

---

## 🏁 Summary

Percentiles help understand where a value stands relative to the entire dataset.
